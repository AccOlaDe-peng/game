## 使用原则

- 禁止使用：来源不明资源、无 License 资源、NC（非商业）限制资源、无法确认商业授权的资源。
- 新增任何第三方资源时，先在 `assets/art/licenses/` 放入原始许可文本，再在本表登记一行。
- 资源包原始许可文本位置：
  - Kenney：`assets/art/licenses/kenney/*.txt`
  - Quaternius：`assets/art/licenses/quaternius-*.txt`
  - Mixamo：`assets/art/animations/mixamo/README.md`
