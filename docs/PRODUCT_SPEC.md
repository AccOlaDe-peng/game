## 1. 文档用途

本文档定义 Project Catalyst 纵向切片的产品目标、玩法规则、内容范围和验收标准。开发实现以本文档和配套的[Godot技术设计文档](./TECHNICAL_DESIGN_GODOT.md)为准。

文档中的内容分为三级：

- **已锁定**：纵向切片必须按此实现；调整前需要更新文档。
- **初始目标**：用于首轮开发和调试，可以根据试玩数据调整。
- **待验证**：必须经过目标玩家测试后才能成为正式规则。

数值变化可以在数据资产中迭代；核心规则、范围或系统边界变化必须同步修改文档。

## 2. 产品概述

### 2.1 一句话介绍

一款以元素附着和组合反应为核心的单机3D俯视角类幸存者游戏。玩家通过自动法术制造元素状态，再用主动催化技能选择反应时机，在持续升级的怪潮中完成地图事件并击败最终首领。

### 2.2 核心玩家幻想

玩家是一名能够操纵战场反应链的元素法师：先用法术铺设状态，再判断怪群位置与元素层数，最后主动催化并引发大范围连锁反应。

### 2.3 核心体验目标

1. **低操作门槛**：移动、闪避和一个主动技能构成主要操作。
2. **高反馈反应**：元素组合必须带来显著的伤害、控制、传播和视听变化。
3. **升级有行为差异**：高价值升级改变法术行为，而不只是增加伤害。
4. **15分钟完整成长**：单局内完成从基础法术到成型构筑的过程。
5. **后期仍然可读**：大量怪物和特效出现时，危险预警和玩家位置始终清晰。

## 3. 设计支柱

### 3.1 元素反应是主要卖点

每套有效构筑都应围绕元素施加、状态维持和组合反应展开。普通法术提供基础输出，主要的清群、控制或爆发来自元素反应。

### 3.2 自动施法，主动催化

普通法术自动寻找目标和释放；玩家负责移动、闪避以及使用“元素催化”选择提前引爆的时机和位置。

### 3.3 构筑改变战斗方式

升级应改变投射物路径、数量、穿透、范围、持续区域、元素层数或反应效果。纯数值升级用于衔接构筑，不作为主要内容。

### 3.4 敌人与事件迫使玩家决策

敌人职责、地图事件和首领技能必须迫使玩家改变移动路线、目标优先级或反应节奏。禁止只依赖提高敌人生命和数量制造难度。

## 4. 目标用户

- 喜欢类幸存者、动作Roguelite和法术构筑的玩家。
- 希望单局时间可控，同时愿意研究组合和重复挑战的PC玩家。
- 使用键鼠或手柄，接受固定俯视角和3D风格化画面的玩家。

体验门槛目标：

- 首次进入游戏后2分钟内理解移动、闪避、自动攻击和经验拾取。
- 首次完整对局中自然触发至少两类元素反应。
- 不阅读外部攻略也能理解基础元素组合。

## 6. 核心循环

```text
进入地图
→ 自动施法击杀敌人
→ 拾取经验并升级
→ 获得新法术或升级已有法术
→ 施加元素并主动催化反应
→ 完成地图事件
→ 应对精英与强化怪潮
→ 击败最终首领
→ 查看构筑、伤害和反应统计
→ 重新开始一局
```

胜利条件：击败最终首领。  
失败条件：玩家生命值降至0。  
纵向切片不提供局内复活。

## 7. 单局节奏

| 时间 | 初始内容目标 |
|---|---|
| 0:00–2:30 | 学习移动、闪避、拾取经验和第一次升级 |
| 2:30–4:00 | 第一次地图事件；构筑出现第二元素 |
| 4:00–6:00 | 快速与远程敌人加入；第一次精英遭遇 |
| 6:00–8:30 | 第二次地图事件；不同敌人职责开始组合 |
| 8:30–10:30 | 高密度怪潮；主要法术进入分支阶段 |
| 10:30–12:00 | 第二次精英压力；完成最终构筑 |
| 12:00–15:00 | 首领预警、入场和首领战 |

15分钟是目标完成时间，不是强制倒计时。首领未被击败时对局继续，直到玩家胜利或死亡。

## 8. 操作和镜头

### 8.1 基础操作（已锁定）

| 行为 | 键鼠 | 手柄 |
|---|---|---|
| 移动 | WASD | 左摇杆 |
| 瞄准元素催化 | 鼠标位置/方向 | 右摇杆 |
| 闪避 | Space | 面键 |
| 元素催化 | 鼠标右键 | 右扳机 |
| 暂停 | Esc | Menu |

普通法术自动释放，不占用额外按键。

### 8.2 移动与闪避

- 玩家可以在水平面自由移动，不受面朝方向限制。
- 闪避提供短距离位移和短暂无敌时间。
- 闪避具有清晰的冷却提示，不使用耐力资源。
- 移动速度、位移距离、无敌时间和冷却均为配置项。

### 8.3 镜头

- 固定倾斜俯视角，不允许玩家自由旋转。
- 镜头平滑跟随玩家，并根据移动方向提供轻微前视空间。
- 屏幕震动强度可调并可完全关闭。
- 首领入场允许短暂演出，但不得长时间剥夺玩家控制。

## 9. 玩家角色

### 9.1 纵向切片角色：元素学徒

角色定位：能够使用全部首发元素的通用角色，用于验证核心系统。

- 初始自动法术：奥术飞弹。
- 主动技能：元素催化。
- 被动特性初始方案：闪避后短时间内，下一次元素催化范围提高。

被动特性属于初始目标，可以根据试玩更换，但不得取消主动催化这一核心操作。

### 9.2 元素催化

元素催化在目标位置或方向产生范围脉冲：

- 对范围内敌人造成少量基础伤害。
- 不施加新的元素。
- 对拥有两种可组合元素的敌人立即结算一次反应。
- 可以用低于普通自动反应的元素层数提前引爆。
- 反应强度仍然按照实际消耗的元素层数计算。
- 催化产生的反应伤害默认不能再次触发主要反应。

该技能的作用是给予玩家反应时机和位置的控制权，而不是单纯成为最高伤害技能。

## 10. 自动法术

### 10.1 通用规则

- 玩家最多同时持有4种自动法术。
- 法术按各自的目标规则自动释放。
- 每个法术最多5级。
- 第3级提供行为分支，第5级完成该分支的进化。
- 升级立即影响运行中的法术。

### 10.2 首发法术

| 法术 | 初始元素 | 战术职责 | 目标规则 |
|---|---|---|---|
| 奥术飞弹 | 无 | 稳定单体输出、元素附魔载体 | 最近敌人 |
| 火球 | 火 | 范围伤害、施加燃烧 | 敌人密集区域 |
| 冰锥 | 冰 | 穿透、减速和冻结 | 最大命中方向 |
| 链式闪电 | 雷 | 传播和清理分散敌人 | 最近未命中目标优先 |
| 环绕法球 | 可附魔 | 近身保护、接触施加元素 | 环绕玩家 |

### 10.3 第3级分支示例

| 法术 | 分支A | 分支B |
|---|---|---|
| 奥术飞弹 | 增加分裂 | 选择一种元素附魔 |
| 火球 | 分裂为小火球 | 留下燃烧区域 |
| 冰锥 | 增加穿透和碎片 | 扩大冰霜扇形 |
| 链式闪电 | 增加弹射次数 | 命中后留下短时电场 |
| 环绕法球 | 增加法球数量 | 扩大轨道并提高元素层数 |

最终数值和第5级效果在玩法数据资产中维护，通过测试后锁定。

## 11. 元素系统

### 11.1 基础元素

| 元素 | 状态 | 基础效果 |
|---|---|---|
| 火焰 | 燃烧 | 持续伤害，可叠加至配置上限 |
| 冰霜 | 寒冷 | 降低移动速度，叠满后短暂冻结 |
| 雷电 | 感电 | 强化传播效果并造成短暂硬直 |

首领不能被完全冻结，但寒冷仍能降低其行动速度，冰相关反应正常生效。

### 11.2 组合反应（已锁定）

纵向切片中的元素组合不区分施加顺序。

| 组合 | 名称 | 主要效果 |
|---|---|---|
| 火 + 冰 | 热裂 | 消耗火冰层数，造成高额碎裂爆发 |
| 火 + 雷 | 等离子爆发 | 范围爆炸，并向附近目标传播燃烧 |
| 冰 + 雷 | 导电冰晶 | 释放链式电击，并传播寒冷状态 |

### 11.3 通用规则

- 普通元素命中达到反应阈值后自动触发。
- 元素催化使用更低的催化阈值提前触发。
- 单次命中最多触发一次主要反应。
- 反应产生的次生伤害默认不能触发新的主要反应。
- 同一目标拥有短暂的反应内部冷却。
- 多个反应同时满足时，按照配置优先级选择一个。
- 反应伤害归属触发反应的法术或主动技能。
- 层数、持续时间、阈值、消耗和倍率全部数据化。

### 11.4 可读性

- 火、冰、雷同时使用颜色、图标和形状区分，不只依赖颜色。
- 敌人头顶只显示对决策有用的状态层数或简化图标。
- 三种主要反应拥有独立的音效、粒子轮廓和短文本提示。
- 高频连续反应合并显示，避免伤害数字和文字遮挡。
- 敌方危险预警的视觉优先级高于玩家伤害特效。

## 12. 经验和升级

### 12.1 经验

- 敌人死亡后掉落经验能量。
- 经验进入拾取范围后自动吸附。
- 升级需求随等级提高，曲线由配置控制。
- 精英和事件提供额外经验，避免只刷普通敌人成为唯一最优路线。

### 12.2 三选一

- 升级时暂停战斗并显示三个不同选项。
- 只显示当前可获得且有效的升级。
- 未满4个法术时，新法术与已有法术升级按权重共同出现。
- 法术槽已满后不再出现新自动法术。
- 初始每局提供1次刷新机会。
- 升级池不能产生没有前置来源的孤立元素强化。

### 12.3 升级类别

- 数值：伤害、范围、冷却、数量、穿透。
- 行为：分裂、弹射、回旋、持续区域、碎片。
- 元素：附魔、状态层数、持续时间、反应倍率和传播能力。

## 13. 敌人设计

### 13.1 普通敌人

| 代号 | 职责 | 核心行为 |
|---|---|---|
| 群行者 | 制造密度 | 缓慢接近，数量多 |
| 追猎者 | 追赶玩家 | 高速移动，生命较低 |
| 重甲兽 | 阻挡路线 | 生命高、体型大、抗轻微硬直 |
| 投射者 | 远程压力 | 保持距离并发射明显预警弹 |
| 爆裂体 | 迫使走位 | 接近后蓄力自爆 |
| 召唤者 | 优先击杀目标 | 召唤群行者并强化附近敌人 |

### 13.2 精英敌人

- 冲锋精英：明显预警后高速冲锋，路径或终点留下短时危险区域。
- 元素守卫：周期性获得一种元素抗性，但不会完全免疫反应。

精英必须拥有独特轮廓、血条和入场提示。

### 13.3 设计规则

- 普通敌人通常只承担一个主要职责。
- 难度主要来自不同职责组合，而不是单个敌人拥有大量技能。
- 高伤害攻击必须提供可识别的预警。
- 不允许玩家无法观察或无法规避的屏幕外高伤害攻击。

## 14. 地图和事件

### 14.1 地图

- 一张开放式竞技场地图。
- 包含少量不可穿越地形和明显地标，不形成复杂迷宫。
- 怪物在镜头外且距离玩家足够远的位置生成。
- 地图边界具有明确视觉提示，不突然使用不可见空气墙。

### 14.2 封印裂隙

地图生成若干持续刷怪的裂隙。玩家需要接近并摧毁或封印它们；完成后获得经验和一次高品质升级选择。

### 14.3 稳定法阵

玩家需要在法阵范围内累计停留指定时间。离开后进度停止或缓慢衰减，使玩家必须改变常规绕圈路线。

事件失败不会直接结束游戏，但会失去奖励并暂时提高怪潮压力。

## 15. 最终首领

### 15.1 首领代号：灰烬巨像

核心技能：

1. 扇形砸击：清晰的地面扇形预警，延迟后造成伤害。
2. 连续冲锋：锁定方向后冲锋，终点生成短时危险区域。
3. 召唤护卫：召唤普通敌人，迫使玩家在躲避和清群之间切换。

首领规则：

- 受到寒冷减速但不会完全冻结。
- 元素反应可以累积失衡值，失衡后短暂暴露弱点。
- 不通过单纯提高生命值延长战斗。
- 首次完整构筑的目标击杀时间为2–4分钟。

## 16. UI和信息

### 16.1 局内HUD

- 玩家生命值。
- 当前等级和经验。
- 对局计时。
- 自动法术图标、等级和冷却状态。
- 元素催化和闪避冷却。
- 当前事件目标与进度。
- 精英或首领血条。

### 16.2 升级界面

每个选项显示：

- 名称、图标和所属法术。
- 行为变化的简短描述。
- 可比较的主要数值变化。
- 相关元素和反应图标。

不得只使用“少量增加”“显著提高”等无法比较的描述。

### 16.3 结算界面

- 生存时间和胜负结果。
- 击杀数和承受伤害。
- 总伤害及各法术伤害。
- 三种元素反应的次数和伤害。
- 最终法术与升级构筑。
- 本局随机种子。

## 17. 视觉与音频方向

### 17.1 视觉

- 3D风格化、清晰轮廓，适合中小团队持续生产。
- 固定俯视角下优先保证单位、掉落和预警的可读性。
- 火、冰、雷分别建立统一的色彩、形状和粒子运动语言。
- 使用层级明确的受击、死亡、冻结、硬直和反应反馈。
- 不以写实高精度角色和开放世界级场景为目标。

具体角色造型、世界观和色板在美术预制作阶段另行确定。

### 17.2 音频

- 每种元素具有独立基础音色。
- 三种主要反应具有可辨认的标志音效。
- 高频攻击音效限制并发并进行轻微变化。
- 玩家受击、低生命、事件和首领预警优先于普通命中音效。

## 18. 设置和可访问性

纵向切片至少提供：

- 总音量、音乐、音效独立调节。
- 分辨率、全屏模式、画质档位和帧率限制。
- 键鼠和手柄提示自动切换。
- 屏幕震动强度调节及关闭。
- 伤害数字开关。
- 元素图标辅助，保证不只依赖颜色。
- 暂停菜单和重新开始确认。

## 19. 存档范围

- 游戏设置和音量。
- 教程提示状态。
- 最佳生存时间、最佳击杀数和首领击败记录。
- 最近一次对局的构筑和统计。

纵向切片不依赖永久属性成长。核心战斗必须在没有局外数值加成的情况下成立。

## 20. 调试与数据需求

开发版本至少记录：

- 对局随机种子。
- 玩家死亡时间和死亡原因。
- 各法术的选择率、伤害和命中数。
- 各升级的选择时间与最终等级。
- 各反应的触发次数、伤害和平均命中目标数。
- 各时间段敌人数和玩家生命变化。

纵向切片不接入外部统计服务，先导出本地日志和结算数据。

## 21. 验收标准

### 21.1 功能验收

- 可以从主菜单开始并完整结束一局。
- 键鼠和手柄均能完成全部操作。
- 五种法术、三种元素和三种反应均能正常获得与结算。
- 升级三选一不会提供无效或冲突选项。
- 两类事件、六类普通敌人、两类精英和一个首领能够完整运行。
- 暂停、升级、失败、胜利、重新开始和返回菜单流程无阻塞。
- 退出并重启游戏后，设置和最佳记录得到保留。

### 21.2 体验验收（待验证）

至少进行两轮、每轮不少于5名目标玩家的无引导测试：

- 80%的玩家在首次对局2分钟内理解基础操作。
- 70%的玩家能解释至少两种元素组合的主要效果。
- 70%的玩家认为元素反应明显影响了升级选择。
- 多数完成首局的玩家愿意立即尝试第二局。
- 不存在一种明显压倒其他选择的唯一构筑。

### 21.3 性能验收

性能指标以配套技术设计文档为准。所有发布判断基于Windows独立导出版本，不以Godot编辑器中的帧率为最终依据。

## 22. 主要风险

| 风险 | 影响 | 应对 |
|---|---|---|
| 元素反应难以理解 | 核心卖点失效 | 首版限制三元素，强化图标、音效和结算统计 |
| 自动反应削弱主动操作 | 战斗趋向挂机 | 催化可低层数提前引爆，并通过事件迫使走位 |
| 元素组合快速膨胀 | 平衡和开发成本失控 | 首版只做三个无顺序反应 |
| 特效遮挡危险 | 公平性和体验下降 | 建立特效层级、透明度与GPUParticles3D并发预算 |
| 大量独立Node造成卡顿 | 无法形成怪潮体验 | 中央数组、MultiMesh、空间网格和性能迁移门槛 |
| 大量独立Node处理造成卡顿 | 难以达到目标实体规模 | C#中央模拟，普通怪和投射物不使用独立逐帧处理 |
| C#内存分配造成卡顿 | 高频战斗出现GC尖峰 | 热路径复用数组、缓冲区和对象池，持续监控分配 |
| 内容不足影响复玩 | 测试结论偏低 | 用升级分支和组合差异验证复玩，不提前堆地图 |

## 23. 纵向切片之后

只有第21节验收通过后，才评估：

- 新角色和专属催化技能。
- 毒、风或奥术等新元素。
- 新地图、首领和事件。
- 横向局外解锁和挑战词条。
- Steam成就、云存档和正式发行功能。
- C++ GDExtension、RenderingServer直连或更深层数据化迁移。

## 24. 变更流程

以下改动需要提升文档版本，并同步检查技术设计：

- 核心循环和操作方式。
- 元素与反应规则。
- 纵向切片内容范围。
- 单局结构和胜负条件。
- 对存档、性能或架构有明显影响的需求。

数值调优不要求每次修改本文档，但规则和范围变化必须记录。
