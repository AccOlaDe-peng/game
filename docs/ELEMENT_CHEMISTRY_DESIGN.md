## 1. 不可删减规则

本系统必须完整保留：五个基元、十种两两融合、融合优先级、融合签名状态、蒸汽热冲击、传导闪电、冰的特殊地位、动作染色、触发接线和效果预算。

冻结不是可抽取载荷卡。冰只能由水与风融合产生，或由明确声明“冰身份”的遗留武器提供。

## 2. 解析顺序

```text
融合
→ 动作染色
→ 特殊反应
→ 旧反应改写
→ 最后处理互斥
```

每次攻击读取不可变构筑快照。飞行中获得新卡不会修改已经生成的投射物、领域或部署物。

| 基元 | 施加概率 | 时长 | 状态 | 规则 |
|---|---:|---:|---|---|
| 火 | 70% | 2.2s | 燃烧 | 每 0.5s 造成 DoT |
| 水 | 70% | 2.0s | 潮湿 | 蒸汽与传导媒介 |

## 4. 融合规则

五基元两两融合，编译时改变整把武器的主身份。装备三个及以上基元时，只应用优先级表中第一条完整配对，不同时产生两个派生身份。

融合施加概率取两个成分概率的较大值，并且最低为 75%；融合状态时长取两个成分时长的平均值。

命中顺序：

1. 按主身份施加签名状态。
2. 各基元按各自概率施加自身状态。
3. 检查本次命中前已经存在的状态，执行交叉反应。

| 优先级 | 配对 | 派生身份 | 命中签名 | 特殊反应 |
|---:|---|---|---|---|
| 1 | 水 + 雷 | 传导闪电 | 感电 | 传导 |
| 2 | 火 + 水 | 蒸汽 | 蒸汽灼烫 DoT | 热冲击 |
| 3 | 水 + 风 | 冰 | 冻结硬控 | 解锁碎冰、冻结时 |
| 4 | 火 + 风 | 烈焰风暴 | 燃烧 | 仅染色、状态、Cue |
| 5 | 火 + 土 | 熔岩 | 燃烧 | 仅染色、状态、Cue |
| 6 | 火 + 雷 | 等离子 | 感电 | 仅染色、状态、Cue |
| 7 | 水 + 土 | 泥沼 | 岩石化 | 仅染色、状态、Cue |
| 8 | 风 + 雷 | 风暴 | 感电 | 仅染色、状态、Cue |
| 9 | 风 + 土 | 沙暴 | 岩石化 | 仅染色、状态、Cue |
| 10 | 土 + 雷 | 晶磁 | 岩石化 | 仅染色、状态、Cue |

## 5. 两条自动交叉反应

### 5.1 蒸汽热冲击

触发条件：

- 火命中本次命中前已经潮湿的目标；或
- 水命中本次命中前已经燃烧的目标。

执行结果：

1. 消耗对应的潮湿或燃烧状态。
2. 清除目标冻结和燃烧。
3. 以目标为中心产生范围冲击。
4. 范围内单位受到水平 9.0m、视觉垂直 2.5m 的击飞反馈；中央模拟只记录 XZ 位移，垂直部分由表现层完成。
5. 地雷命中不触发热冲击。

### 5.2 传导闪电

触发条件：雷命中本次命中前已经潮湿的目标。

执行结果：

1. 以目标为网络源，在反应半径内寻找所有潮湿单位。
2. 网络人数为 `N`，单体伤害倍率为 `1 + 0.35 × (N - 1)`。
3. 对网络内每个单位造成一次雷击。
4. 每个命中单位获得感电并消耗潮湿。
5. 候选目标按距离、稳定实体 ID 排序，保证固定 Seed 可复现。
6. 地雷命中不触发传导。

## 6. 冰的特殊地位

- 水 + 风融合后，整把武器获得冰身份。
- 冰命中立即施加冻结硬控，而不是积满六层才冻结。
- 目标首次进入冻结时发送“冻结时”事件。
- 碎冰卡只有在武器拥有冰身份时才进入候选池。
- 碎冰检查命中开始前的标签；同一击先冻结再击杀不触发碎冰。
- 必须击杀一个在命中前已经冻结的目标，才生成冰晶碎片。

## 7. 动作染色

爆炸、碎片、新星和领域默认无属性，执行时根据主载荷解析：

| 主身份 | 爆炸 | 碎片 | 新星 | 领域 |
|---|---|---|---|---|
| 中性 | 中性爆炸 | 中性碎片 | 中性新星 | 冰领域回退仅用于旧内容迁移 |
| 冰 | 冰晶爆裂 | 冰晶碎片，穿透 1 | 冰霜新星 | 冰原领域 |
| 火 | 火焰爆发 | 火种碎片 | 火焰新星 | 烈焰领域 |
| 标记 | 标记扩散 | 追猎碎片 | 标记脉冲 | 不生成元素领域 |
| 蒸汽 | 蒸汽爆裂 | 蒸汽碎片 | 蒸汽新星 | 蒸汽领域，脉冲推开 |
| 其他融合 | 使用“风·爆裂”“雷·碎片”等通配名称 | 范围效果并施加该身份签名状态 |

- AOE 半径为 `max(2.2m, EffectRadius)`。
- 爆炸自带半径 +0.8m，常规结果约 3.0m。
- 击杀爆炸不攻击已死亡主目标；新星允许以死亡位置为中心执行。
- 领域持续 2.4s，每 0.45s 脉冲。
- 碎片单次 2–6 发，弹速为原武器 0.85 倍。

## 8. 触发接线

| 条件模块 | 事件 | 产出动作 | 伤害倍率 |
|---|---|---|---:|
| 冻结时 + 碎片 | 首次冻结 | 碎片 | 0.70 |
| 穿透时 + 碎片 | 穿透 | 碎片 | 0.55 |
| 弹射时 + 碎片 | 弹射 | 碎片 | 0.55 |
| 弹射时 + 弹体复制 | 弹射 | 复制弹 | 0.50 |
| 冲刺时 + 领域 | 玩家冲刺 | 领域 | 1.00 |
| 领域 + 火或击杀触发 | 击杀 | 领域 | 1.00 |
| 状态传播 | 击杀 | 传播 | 1.00 |
| 新星 | 击杀 | 新星 | 0.75 |

火状态传播要求目标在击杀前已经燃烧。单次传播最多影响 8 个目标。

## 9. 反应卡改写

| 卡牌 | 安装条件 | 编译结果 |
|---|---|---|
| 碎冰 | 武器拥有冰身份 | 改写为“击杀已冻目标 → 冰晶碎片” |
| 燃爆传播 | 武器拥有火成分 | 改写为“击杀燃烧目标 → 状态传播” |
| 暴击回响 | 投射物核心 | 改写为“暴击 → 弱化复制弹” |
| 死亡新星 | 有效击杀来源 | 改写为“击杀 → 可染色新星” |

旧术语统一迁移：碎冰→碎片、燃爆→传播、回响→复制、死亡新星→新星。

## 10. 构筑示例

- 冰晶穿透：步枪 + 穿透 + 水 + 风 + 冻结时 + 碎片。
- 碎冰清场：冰晶穿透 + 碎冰。
- 蒸汽热冲击：不同武器分别提供火与水，或单武器融合火水。
- 传导闪电：一把武器铺潮湿，另一把高频雷武器触发网络。
- 野火：步枪 + 多重 + 火 + 状态传播 + 领域。
- 弹珠猎杀：圆盘 + 弹射 + 标记 + 追踪 + 弹射时 + 复制。
- 冲刺领域：地雷 + 冲刺时 + 领域 + 任意元素。
- 熔岩爆：火 + 土 + 爆炸；获得熔岩身份，但没有额外交叉爆炸。

## 11. 性能与递归预算

- 最大链深：4。
- 单次根事件预算：32。
- 单事件最多 4 次反应、8 个子动作。
- 场上投射物软上限约 200；压力模式可提高，但不用于正常平衡。
- 单次碎片最多 6 发。
- 单次传播最多 8 个目标。
- 领域、网络和传播查询必须使用现有空间网格，不创建大量物理节点。
- 反应伤害默认不能再次触发主反应，除非定义明确声明。

## 12. 与当前版本的迁移

当前火、冰、雷三反应属于旧原型。正式实现 V2 时：

1. 火焰继续映射为火。
2. 冰霜武器保留外观，但数据身份迁移为水 + 风形成的冰。
3. 链式闪电映射为雷，可与潮湿组成传导。
4. 旧“火 + 冰热裂”不再作为自动化学反应。
5. 旧“火 + 雷等离子爆发”迁移为等离子融合身份，只染色、施加感电和 Cue。
6. 旧“冰 + 雷导电冰晶”不再运行；真正的传导使用水 + 雷。
7. 元素催化只提前执行已经满足状态条件的热冲击或传导，不凭空创造第三种反应。
8. 旧存档中的法术和升级 ID 通过版本化迁移表转换，不直接删除存档。

## 13. 验收测试

必须具备自动测试：

1. 十种两两融合逐项验证。
2. 三个以上基元只选择优先级最高的完整配对。
3. 标记不参与融合。
4. 火打潮湿与水打燃烧均触发热冲击。
5. 雷打潮湿触发传导，水打感电不触发传导。
6. 地雷不触发热冲击和传导，但仍施加载荷状态。
7. 冰由水风产生，并发送首次冻结事件。
8. 同一击先冻后击杀不触发碎冰。
9. Boss 状态时长为普通敌人的 0.25。
10. 固定 Seed 下传导目标顺序和伤害一致。
11. 反应伤害不会无限递归。
12. 所有效果遵守链深、根预算和子动作上限。
