# Project Catalyst 世界观与叙事设计

> 文档状态：概念基线  
> 适用范围：世界观、角色、关卡包装、UI、文案、音频与后续内容设计  
> 核心原则：界面不是故事之外的菜单，而是玩家接触这个世界的主要媒介。

## 1. 文档目的

本文档为 Project Catalyst 建立统一的背景故事、世界规则与界面叙事基线，供后续产品、玩法、视觉、UI、关卡、音频和程序实现参考。

本文档不锁定具体美术资产，也不要求现阶段立即实现完整剧情。任何新增内容都应优先满足以下目标：

- 为元素反应、自动施法、自动催化与局内构筑提供合理的世界观解释。
- 让每次对局成为一次明确的世界内行动，而非脱离叙事的玩法循环。
- 让 UI、术语、反馈和系统状态共同讲述故事。
- 使用可逐步扩展的碎片化叙事，避免依赖大量过场动画。
- 保证叙事包装不损害操作效率、战斗可读性与数据准确性。

## 2. 一句话世界观

在元素法则崩坏后的世界中，玩家作为“催化局”的远征执行者进入现实裂隙，通过组合与引爆元素相态来修复世界，并逐渐发现这场灾难可能是某个未知意识理解人类的过程。

## 3. 核心体验幻想

玩家不是传统法师，而是一名携带实验性装备、进入异常区域执行任务的元素远征者。

玩家在战斗中应持续感受到：

- 自己正在读取并操纵世界的基础法则。
- 每次升级都是一次有风险的现场装备重构。
- 敌人不是随机怪物，而是崩坏现实产生的失败造物。
- UI 是真实存在的任务终端和相态观测设备。
- 每次深入裂隙，都在接近一段被机构掩盖的历史。

## 4. 世界背景

### 4.1 赫利昂

故事发生在名为“赫利昂”的世界。

赫利昂曾建立高度发达的元素工程文明。火、冰、雷、流体等元素并不被视为传统魔法，而是现实物质在不同条件下呈现的基础“相态”。研究者使用一种名为“以太”的媒介观测、储存和转换这些相态，并以此驱动城市、交通、武器与医疗设施。

遍布大陆的稳定网络维持着元素之间的边界，也维持着人类所认知的现实。

### 4.2 白塔与原初催化炉

“白塔”是旧时代最先进的元素研究机构，也是现今催化局的前身。

白塔认为所有元素都源自同一种基础存在。只要让不同相态在绝对平衡中持续转化，就能制造永不枯竭的能源。为此，白塔建造了“原初催化炉”。

实验成功运行了七秒。

第八秒，催化炉开始反向改写现实。

白塔和周围城市从正常空间中消失，大陆各处出现相互连通的异常区域。元素不再完全服从自然规律：火焰能够寄生于生命，寒冰可以保存记忆，雷电会在意识之间传递，物质则可能在多种相态之间反复转换。

这场事件被称为“大失衡”。

### 4.3 裂隙

裂隙不是传统意义上的传送门，而是现实法则失去一致性的区域。

进入裂隙后，空间、时间、记忆和元素相态会相互干扰。相同的地点可能以不同结构重复出现，死者的行为可能被重新演算，强烈记忆可能凝结成可回收的物质。

催化局将每一种可进入的裂隙状态记录为一个“相位坐标”。游戏中的 Seed 即对应一次裂隙演算的相位坐标。

### 4.4 催化局

大失衡后，幸存的研究人员、工程师与地方武装重组为“催化局”。

催化局的公开任务是：

- 监测并封锁裂隙。
- 派遣远征人员进入异常区域。
- 修复稳定节点，阻止裂隙扩张。
- 回收旧文明技术和记忆碎片。
- 消灭可能进入现实的灾变核心。

催化局对外宣称大失衡是一场无法预料的技术事故。但其内部档案存在大量删除、重写和权限封锁。随着远征深入，玩家会发现催化局掌握的真相比公开历史更多。

## 5. 世界规则

### 5.1 元素相态

元素是构成现实的基础相态，而不是互不相关的魔法学派。

不同元素可以在目标、环境或装备中积累。当两种相态同时达到反应条件时，它们会发生融合、释放或结构崩溃，形成元素反应。

元素系统的表现必须同时使用颜色、符号、声音和运动特征，不得仅依赖颜色区分。

### 5.2 元素催化

“元素催化”是远征装备自主干预相态平衡的协议。行者不能通过技能按键直接释放催化，只能通过构筑、移动与聚怪改变协议的判断结果。

正常情况下，元素需要积累到稳定阈值才会自然反应。催化装置持续充能并监测附近相态，在预测收益达到安全阈值后自动选择区域，降低反应阈值，使尚未完全形成的组合提前释放。

世界观意义上，催化不是凭空制造力量，而是观测设备按照预设协议自动破坏目标内部短暂形成的平衡。玩家通过现场重构改变协议，而不是亲自施放能力。

### 5.3 记忆碎片

裂隙中的强烈意识、知识和情绪会在以太中凝结成“记忆碎片”。

记忆碎片兼具三种作用：

- 局外成长和解锁资源。
- 旧文明技术与历史的载体。
- 未知意识与玩家建立联系的媒介。

记忆碎片不应只表现为普通货币。获得重要碎片时，应允许玩家解锁档案、语音、异常图像或被修改的任务记录。

### 5.4 敌人的形成

裂隙敌人主要分为三类：

- **蚀变体**：进入裂隙后被元素重新塑造的生命。
- **残响体**：由死者记忆、行为或情绪不断重复形成的拟态存在。
- **构装体**：仍在执行旧时代命令的机械与元素设施。

同一敌人可以同时具有两种来源，但设计时必须明确其主体来源，以统一造型、攻击方式、声音和掉落表现。

### 5.5 灾变核心

当裂隙持续吸收能量并完成自我稳定后，会形成能够影响现实的“灾变核心”。Boss 是灾变核心的具象化结果。

玩家在单局中生存、战斗和触发元素反应的过程，也在加速当前裂隙的演算。因此最终 Boss 出现并非单纯的时间事件，而是裂隙完成实体化的结果。

## 6. 玩家每局的叙事闭环

每局游戏是一项正式的裂隙远征任务：

1. 选择获得授权的行者。
2. 装载角色对应的初始武器核心。
3. 锁定相位坐标并进入裂隙。
4. 消灭异常实体，吸收元素余质。
5. 使用余质进行现场装备重构。
6. 封印裂隙或稳定法阵等关键节点。
7. 阻止灾变核心完全进入现实。
8. 回收记忆碎片、战斗记录和异常样本。
9. 返回基地，更新档案与解锁内容。

失败代表远征者失去战斗能力或相位连接中断，不代表所有叙事信息都被抹除。远征装备可以在连接终止前上传部分记录，从而解释失败后仍能保留局外进度。

## 7. 玩法系统的世界观映射

| 玩法概念 | 世界内解释 | 建议 UI 术语 |
| --- | --- | --- |
| 开始游戏 | 启动一次裂隙远征 | 启动试炼 / 开始下潜 |
| 角色选择 | 选择获得任务授权的行者 | 行者授权 |
| Seed | 当前裂隙的演算状态 | 相位坐标 |
| 经验值 | 异常实体释放的可吸收能量 | 元素余质 |
| 升级 | 装备用余质进行即时改写 | 现场重构 |
| 三选一 | 终端生成的安全重构方案 | 重构方案 |
| 刷新 | 放弃当前演算并重新推演 | 重新演算 |
| 元素催化 | 自主协议评估区域并降低元素反应阈值 | 催化协议 |
| 元素反应 | 相态融合或结构崩溃 | 反应名称 |
| 局外货币 | 凝结的意识和技术记录 | 记忆碎片 |
| 事件 | 修复裂隙中的关键设施 | 现场目标 |

术语替换应分阶段实施。面向玩家的首版文案优先保证易懂，可以采用“常用词 + 世界观副标题”的形式，例如“选择升级｜现场重构”。

## 8. 首发角色

### 8.1 元素行者

**定位：** 标准远征人员、元素反应入门角色。  
**初始武器：** 脉冲步枪。  
**玩法特征：** 以稳定高速攻击建立元素组合，由优化后的自动催化协议完成反应。

元素行者接受过完整的人工相态适配，可以比普通人更稳定地承载多种元素。催化局将其视为最可靠的实验执行者。

随着远征深入，他开始听见记忆碎片中的声音，并发现自己的部分童年记忆可能由机构植入。

**角色主题：** 我是使用元素的人，还是元素塑造出的工具？

**界面表达：**

- 档案完整、格式标准，带有实验编号和授权等级。
- 角色状态突出适配度、反应效率和安全评级。
- 后期逐渐出现档案日期冲突和身份记录异常。

### 8.2 回响猎手

**定位：** 裂隙污染区幸存者、临时合作人员。  
**初始武器：** 弹射圆盘。  
**玩法特征：** 记录目标的元素回响，在敌群之间弹射并重复命中。

回响猎手长期在污染区依靠猎杀蚀变体生存。他不信任催化局，与机构合作只是为了追踪一段疑似来自失踪亲人的求救信号。

随着剧情推进，他会发现信号可能并不属于任何人类，而是裂隙根据他的记忆制造出的诱饵。

**角色主题：** 记忆是真相，还是某种存在用来操纵你的回声？

**界面表达：**

- 档案包含大量涂黑字段和临时授权标记。
- 解锁提示使用“权限不足”或“合作协议未生效”。
- 任务记录中可出现未经催化局确认的个人批注。

### 8.3 裂隙工匠

**定位：** 前稳定装置工程师、部署与控场专家。  
**初始武器：** 元素地雷。  
**玩法特征：** 捕捉、压缩并延迟引爆元素相态，以装置控制战场。

裂隙工匠曾参与稳定设备的开发，后因一次失败任务离开催化局。她知道催化局隐瞒了部分事故记录，并认为自己的原型设备仍留在裂隙深处。

她重新加入远征的目的，是找回原型机并确认当年失败的真正原因。

**角色主题：** 导致灾难的技术，是否仍然能够修复世界？

**界面表达：**

- 部署物具有机械编号、功耗和稳定参数。
- 升级卡更接近工程模块与装配图。
- 系统提示会被角色的手写式批注覆盖或修正。

## 9. 首发 Boss：灰烬巨像

灰烬巨像曾是原初催化炉的首席研究主管，暂定名为“赫克托”。

事故发生时，他试图用自己的身体和相态适配装置封闭炉心。裂隙保留了他的最后一条指令，并将其不断放大：

> 保持反应继续。

如今的灰烬巨像不是完整的人类，而是研究主管、封锁装置与灾变核心融合后的存在。它制造火焰危险区、召唤守卫并维持催化循环，并非出于单纯的攻击欲，而是在继续执行实验。

Boss 只受减速而不会被冻结，是因为其结构由持续反应维持，无法进入完全静止状态。元素反应积累失衡值，则代表玩家正在破坏支撑它存在的相态循环。失衡后的易伤窗口，是其人类意识短暂重新出现的时刻。

击败灰烬巨像后，应逐步释放被隐藏的实验记录，而不是立即完整解释真相。

## 10. 主线结构

主线采用四幕式推进，主要通过档案、任务变化、角色对话和 UI 异常呈现。

### 第一幕：执行任务

- 玩家相信催化局正在修复世界。
- 任务说明可靠、完整，界面秩序清晰。
- 灰烬巨像被描述为普通灾变核心。

### 第二幕：记录冲突

- 回收的记忆碎片与官方记录出现矛盾。
- 不同角色看到的档案内容可能不同。
- UI 偶尔显示未经系统生成的信息。

### 第三幕：追溯事故

- 玩家确认催化局的前身参与制造了大失衡。
- 白塔可能在实验开始前就检测到某种意识。
- “事故”可能是一次主动接触实验。

### 第四幕：决定未来

玩家最终面对三种可能方向：

- 永久关闭裂隙，放弃其中保存的人类记忆与技术。
- 控制裂隙，将其作为文明重建的能源与工具。
- 与裂隙中的未知意识建立有限沟通，接受不可预测的改变。

首个可玩版本不需要实现完整分支结局，但新增内容不应提前否定任何一种可能。

## 11. 未知意识

裂隙背后可能存在一个尚未完成自我定义的巨大意识。

它无法直接理解人类，只能通过元素、空间和记忆反复重建观察到的事物。敌人、重复城市、残响体以及部分异常 UI 信息，可能都是它尝试理解人类的结果。

叙事中不应过早确认它是神、外星生物、人工智能或自然现象。前期只提供可被多种解释支持的证据。

未知意识的表达原则：

- 极少使用完整的人类语言。
- 优先使用重复、错位、组合和结构变化。
- 不直接威胁玩家，而是表现出观察、模仿和邀请。
- 它对个体记忆的理解准确，但对情感意义的理解存在偏差。

## 12. 界面叙事总则

### 12.1 核心视觉命题

最终视觉建议融合：

- 70% 炼金学院式的秩序、精度与信息清晰度。
- 20% 工业远征设备的耐用感与战斗压力。
- 10% 东方星象式的抽象相态符号与神秘感。

这不是简单的风格拼贴，而是三个叙事层级：

- 催化局使用理性、统一、可信的机构视觉。
- 远征设备强调机械、战术和生存功能。
- 裂隙通过星图、同心结构和异常符号侵入前两者。

**总原则：越靠近人类世界，界面越理性；越深入裂隙，界面越像未知意识的语言。**

### 12.2 信息优先级

任何叙事装饰都不得干扰以下信息：

1. 玩家生命与危险状态。
2. 当前目标和 Boss 状态。
3. 元素附着、反应条件与催化协议状态。
4. 升级收益和构筑变化。
5. 操作提示。
6. 世界观补充信息。

装饰性扫描、噪声、故障和异形文字不得覆盖核心操作区域。

### 12.3 渐进式侵蚀

界面异常应随叙事进度逐渐出现：

- 初期：规则网格、完整档案、稳定动画。
- 中期：数据冲突、未知波形、短暂错位、被修改字段。
- 后期：裂隙符号与机构界面产生结构融合。

界面异常必须可关闭或降低强度，并受可访问性设置控制。

## 13. 分页面界面叙事

### 13.1 主界面：催化局任务终端

主界面是一台远征任务终端，而不是抽象菜单。

建议内容：

- 当前行者授权状态。
- 初始武器核心。
- 相态适配或角色特征。
- 最佳远征记录。
- 记忆碎片余额。
- 尚未解密的档案入口。
- 当前可用相位坐标。

主要操作建议使用“启动试炼”或“开始下潜”。设置入口属于终端系统设置。

### 13.2 战斗 HUD：相态观测器

HUD 是行者携带的战术观测设备。

- 元素状态同时使用色彩和独立符号。
- Boss 失衡条表现为结构稳定度变化。
- 催化协议显示充能、候选评估、等待条件与自动执行结果，不显示技能按键。
- 事件目标表现为现场稳定任务。
- 反应触发采用类似公式组合的短促动画。
- 裂隙侵蚀可以通过边缘失真表达，但中心战斗区必须保持清晰。

### 13.3 升级界面：现场重构演算

升级时，终端使用回收的元素余质生成三个安全重构方案。

每张升级卡应优先展示：

- 模块名称和来源。
- 稀有度或安全等级。
- 当前值与升级后数值。
- 与现有武器、模块或元素的协同关系。
- 功耗或其他构筑限制。

允许使用一句短警告强化世界感，例如：“连续装载可能导致热失控。”

后期可以出现来源未知的“异常方案”。异常方案可拥有特殊收益与代价，但不能仅依靠随机负面效果制造选择压力。

### 13.4 结算界面：远征报告

结算页是一份被催化局归档的正式任务报告。

必须清晰显示：

- 胜利或连接中断状态。
- 生存时间、击杀数、承伤和总伤害。
- 法术伤害与元素反应统计。
- 最终构筑。
- Seed 对应的相位坐标。
- 记忆碎片奖励。

可扩展信息：

- 裂隙稳定率。
- 回收的异常记录。
- 新解锁档案。
- 角色侵蚀程度。
- 系统无法解释的数据段。

叙事术语不能替代明确反馈。即使显示“信号中断”，也应让玩家立刻理解本局为失败。

### 13.5 设置与可访问性

设置属于远征终端与观测器配置。

以下选项同时具有功能和世界内解释：

- 镜头震动：动能补偿反馈。
- 伤害数字：战斗数据投影。
- 元素辅助：相态符号增强。
- 音量设置：通信与反馈通道。

不得为了世界观术语而降低选项可理解性。主标签继续使用通用名称，世界内解释只作为副文案。

## 14. 文案风格指南

### 14.1 催化局文案

- 冷静、精确、克制。
- 使用编号、权限、稳定度和风险等级。
- 避免情绪化表达。
- 对危险使用技术性描述，隐约体现机构对个体的疏离。

示例：

> 相位坐标已锁定。结构稳定度低于安全阈值。允许执行一次远征连接。

### 14.2 角色文案

- 元素行者：谨慎、求证，逐渐产生身份怀疑。
- 回响猎手：直接、警惕，不接受机构式模糊表达。
- 裂隙工匠：技术化、带个人批注，重视实际故障而非行政结论。

### 14.3 未知意识文案

- 短句、重复、错位。
- 像是在学习人类语言，而非故意制造恐怖。
- 可以正确复述事实，却错误理解事实之间的情感关系。

示例：

> 你们把保存称为失去。  
> 我已经保存了他们。  
> 为什么你仍在寻找？

## 15. 音频叙事方向

- 催化局界面：清晰的机械确认音、继电器、柔和玻璃共振。
- 战斗设备：短促、可定位、优先传达冷却与危险。
- 元素反应：不同元素拥有独立音色，组合反应叠加两种来源并加入第三种结果音。
- 裂隙异常：反向尾音、延迟重复、无法确定来源的低频脉冲。
- 未知意识：避免普通怪物吼叫，优先使用多层人声、空间重叠与不完整发音。

## 16. 碎片化叙事载体

为了控制制作成本，主线优先通过以下载体推进：

- 远征前后的短通信。
- 角色选择页中的档案变化。
- 结算页解锁的研究记录。
- 记忆碎片中的一句话或短音频。
- 同一地点在不同相位坐标中的视觉变化。
- Boss 战前后短暂恢复的人类语言。
- 催化局记录与个人记录之间的矛盾。
- UI 中极短、可选关闭的异常信息。

单条叙事内容应尽量短小，并在多局游戏中逐步组合成完整含义。

## 17. 分阶段实现建议

### 阶段一：术语与包装

- 确认核心词汇表。
- 将 Seed 补充标注为相位坐标。
- 将结算包装为远征报告。
- 为三位角色加入简短档案和身份标签。
- 为灰烬巨像加入一条战前和一条战后文本。

### 阶段二：档案与解锁

- 新增轻量档案页面。
- 记忆碎片同时承担解锁档案的功能。
- 根据 Boss 完成状态推进第一批记录。
- 在主界面展示一条最近回收的异常记录。

### 阶段三：界面叙事变化

- 根据叙事进度改变少量终端内容。
- 添加可访问性可控的异常视觉。
- 让不同角色看到不同的任务批注。
- 引入异常升级卡的原型机制。

### 阶段四：主线扩展

- 增加新灾变核心与对应历史人物。
- 完成白塔事故记录链。
- 建立三个终局方向，但避免简单善恶二分。

## 18. 设计约束

后续设计必须遵循：

- 元素仍是首要玩法卖点，叙事不能把重点转移为纯机构阴谋。
- 催化局不能被写成单纯邪恶组织，其隐瞒应有现实压力和内部派系原因。
- 未知意识不能过早定性，必须保留解释空间。
- 角色故事需要与其武器和玩法行为相关联。
- 世界观术语必须能够被新玩家快速理解。
- 关键战斗信息永远优先于沉浸式装饰。
- 故障效果、闪烁和色彩编码必须满足可访问性要求。
- 任何永久成长都应被解释为知识、授权或适配能力，而非无条件数值碾压。

## 19. 待定事项

以下内容保留为后续决策，不在当前阶段锁死：

- 世界名“赫利昂”是否作为最终名称。
- 白塔和催化局的正式标志与组织结构。
- 原初催化炉实验是否由未知意识主动诱导。
- 三位角色的姓名、年龄、外形和具体关系。
- 灰烬巨像的人类姓名“赫克托”是否保留。
- 冰、火、雷之外的完整元素体系及世界规则。
- 裂隙是否真实保存了死者意识，还是仅复制了行为与记忆。
- 最终结局是否采用分支选择或多周目逐步揭示。

## 20. 核心创作检验

新增角色、系统、页面或敌人进入制作前，应回答以下问题：

1. 它如何强化元素反应或局内构筑？
2. 它在世界中为什么存在？
3. 玩家通过什么行为发现它的故事？
4. 它是否能通过 UI、动作或环境表达，而不依赖长篇说明？
5. 它是否保持核心信息清晰并符合可访问性要求？

如果只能回答“看起来很酷”，则该设计尚未完成。
